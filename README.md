#  Master Mind 🧠🧠

Master Mind game is a Game where you are given a code with length of 4 and you try to crack the code
in 10 attempts max.

The game will tease your brain and enhance it to another level

## 📱 Features


- 👨‍💻 **Customized code** – You can set your own code and test your firends using -c codeNumber 🔒.
- ⚙️ **Customized Attempts** – You can set your own number of attemts if you want to take your time and think using -t attemptsNumber.
- ✅ **Input Validation** – All the input are validated even the one that comes from the args.
- 🛑 **Exit** – you can exit mid game using Ctrl + z if windows or Ctrl + d for Mac and Linux 
.

## 💻 installation

1- download [Visual Studio Code](https://code.visualstudio.com/download) to open the code.

2- install c# from [HERE](https://code.visualstudio.com/docs/languages/csharp).


3-  Clone the repo from me
```
git clone https://github.com/AymanAlzahrani/Master-Mind.git
 ```


4- go to the cloned repo on your preffered location using the terminal
```
 cd desktop/master_mind
```
5- now enter this line to open VSCode like magic 🪄🪄
```
code .
```

6- run this code to run the programm 
```
dotnet run
```

## 💻 Feature Usage

1- to give your custmoized code (must be 4 uniqe numbers) run this command after making the directory on publish
```
./my_mastermind -c 1234

```
OR

on the same app folder

```
dotnet run -- -c 1234

```
2- to give your custmoized number of attempts (must be a number) run this command after making the directory on publish
```
./my_mastermind -t 12

```
OR

on the same app folder

```
dotnet run -- -t 12

```

3- to Exit the app you can use one of these option

a- Mac and Linux: Ctrl+D and then Enter 

b- Windwos Ctrl+Z and then Enter

c- Linux and Windos Ctrl+c and for Mac Command + C
